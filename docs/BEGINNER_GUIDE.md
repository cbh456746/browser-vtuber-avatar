# 처음 시작하기 — 컴퓨터 지식이 없어도 괜찮습니다

## 1. 준비할 것

- Windows 10/11 64비트 컴퓨터.
- 직접 사용하거나 변형할 권한이 있는 캐릭터 일러스트 한 장.
- 그림 제작을 맡길 Codex와 이미지 생성 도구 접근 권한.
- 방송할 때 사용할 OBS. 얼굴 추적을 쓸 때만 VTube Studio도 준비합니다.

이 앱의 소스 ZIP과 완성된 실행용 ZIP은 다릅니다. GitHub의 초록색 Code 버튼으로 받는 소스는 바로 실행하는 제품이 아닙니다. 정식 실행용 Release가 없을 때는 README의 요청문과 그림을 Codex에 전달해 빌드를 맡겨 주세요.

## 2. 내 캐릭터 만들기

1. Codex에 그림을 첨부합니다.
2. 이 저장소 링크를 함께 보내고 “워크플로우에 따라 내 아바타와 Windows 실행파일을 만들어 주세요”라고 요청합니다.
3. Codex가 만드는 방향·표정 비교 이미지를 확인합니다. 얼굴·머리 장식·좌우가 이상하면 구체적인 위치를 알려 수정합니다.
4. 완료되면 실행용 ZIP과 캐릭터 폴더, 검사 결과를 받습니다.

작은 그림에 없던 각도는 AI의 추정입니다. 한 번에 항상 완벽한 그림이 나오는 것은 아니며 최종 외형 확인이 필요합니다. 제작 도구가 없는 경우 에이전트가 임의의 유사 그림으로 완료했다고 표시해서는 안 됩니다.

## 3. 앱 실행하기

1. 신뢰할 수 있는 제작자에게서 받은 **실행용 ZIP**을 새 폴더에 모두 풉니다.
2. 폴더 안의 **Illustration Avatar Studio.exe**를 더블클릭합니다.
3. 기본 캐릭터 Orbit과 설정 창이 나타나는지 확인합니다.

exe만 바탕화면에 복사하지 마세요. 옆의 DLL·resources 폴더도 앱의 일부입니다. 바탕화면에 놓고 싶다면 파일 복사 대신 바로가기를 만듭니다. Node.js·npm·터미널을 직접 설치하거나 입력할 필요가 없습니다.

미서명 검증 빌드는 Windows가 제작자를 확인하지 못할 수 있습니다. 보호 기능을 끄지 말고, 배포자와 검사 결과를 확인할 수 없다면 실행을 멈추세요. 현재 소스 공개는 정식 실행파일 배포를 뜻하지 않습니다.

## 4. 캐릭터 불러오기

1. 앱의 **내 캐릭터 불러오기**를 누릅니다.
2. Codex가 전달한 캐릭터 폴더에서 **avatar.json**을 고릅니다.
3. 캐릭터 이름과 그림이 바뀌는지 확인합니다.

JSON 파일을 열어 편집할 필요는 없습니다. 파일을 선택하기만 하면 됩니다. 폴더에는 avatar.json과 frames 폴더가 함께 있어야 합니다. 원본 일러스트 PNG를 이 버튼으로 고르는 것이 아닙니다.

잘못된 파일, 누락된 프레임, 허용되지 않은 형식은 앱이 거부합니다. 메시지가 뜨면 파일을 임의로 고치기보다 Codex에 검사와 재구성을 요청합니다.

## 5. 움직임 고르기

**수동:** 미리보기 아래 좌우·상하·입 슬라이더와 눈 감기 버튼으로 확인합니다.

**마이크:** 입력 방식에서 마이크를 고르고 사용 동의 창에서 허용합니다. 말해 보고 입이 움직이는지 확인합니다. 조용한데 입이 열리면 말하기 문턱을 높입니다. 다른 모드로 바꾸면 마이크를 종료합니다.

**얼굴 추적:** PC VTube Studio에서 API를 켠 뒤 앱에서 얼굴 추적을 선택하고 연결을 누릅니다. VTube Studio의 승인 창을 허용합니다. 이 앱은 직접 카메라를 켜지 않고 VTube Studio가 제공하는 값만 읽습니다.

## 6. 방송과 종료

**방송 화면 열기**를 누르고 [OBS 안내](OBS_GUIDE.md)를 따릅니다. 설정 창은 방송 화면과 다르므로 올바른 창을 선택하세요.

방송을 마치면 설정 창을 닫습니다. 방송 창과 추적 연결도 함께 종료됩니다. OBS의 마이크·카메라 소스는 OBS에서 별도로 관리합니다.

## 문제가 생겼을 때

| 증상                     | 해볼 일                                                    |
| ------------------------ | ---------------------------------------------------------- |
| 실행이 안 됨             | ZIP을 완전히 풀었는지, 실행파일 옆 resources가 있는지 확인 |
| 내 캐릭터가 안 보임      | avatar.json과 frames를 함께 받았는지 확인                  |
| 얼굴 추적이 안 됨        | VTube Studio 실행·API·승인·포트를 확인                     |
| 입이 계속 열림           | 마이크 모드의 문턱을 높이고 주변 소음을 줄임               |
| OBS에서 초록 배경이 보임 | 선택한 소스에 크로마키 필터 추가                           |
| 방송에 목소리가 안 나옴  | OBS 오디오 입력을 따로 추가                                |

지원 요청에는 오류 문장과 앱 버전 정도만 보내세요. 전체 바탕화면·대화·토큰·개인 폴더 경로를 공개 게시하지 않습니다.
