# 위협 모델과 방어 전략

## 지킬 자산과 신뢰 경계

사용자의 원본·생성 캐릭터, VTube Studio 인증 토큰, PC 파일, 마이크 입력, 방송 화면, GitHub 인증과 실행파일 무결성을 보호합니다.

사용자 메시지 → 저장소의 검토한 작업 절차 → 이미지 생성 도구 → 비공개 생성물 → 데이터 전용 캐릭터팩 → 샌드박스 렌더러 → 제한된 IPC/main → 로컬 VTube Studio를 서로 다른 경계로 취급합니다. 하나를 신뢰한다고 나머지에 임의 권한을 주지 않습니다.

## 잔여 위험

이것은 전문 외부 침투 테스트나 침해 불가능성 인증이 아닙니다. 같은 Windows 계정·관리자 권한을 가진 악성 프로그램, VTube Studio 포트를 먼저 차지한 로컬 프로그램, OS·Electron·이미지 디코더의 미지 취약점은 앱 하나로 해결할 수 없습니다.

VTube Studio 로컬 API는 이 앱이 제어하는 서버가 아닙니다. 다른 호스트나 임의 원격 서버에 연결하는 기능은 제공하지 않습니다. 인증 토큰이 필요한 작업은 VTube Studio의 실제 승인 체계에 의존합니다.

프롬프트 인젝션 대응은 에이전트가 신뢰 경계를 지키는 운영 규칙까지 포함합니다. 이미지 속 문자열을 발견하거나 manifest를 거부했다고 모든 형태의 인젝션이 제거됐다고 주장하지 않습니다.

실제 마이크·VTube Studio·OBS·장시간 방송은 자동 모의 시험과 별도로 검증해야 합니다. 새 의존성·포맷·권한·공개 기능을 추가할 때 이 위협 모델과 검사를 함께 갱신합니다.
