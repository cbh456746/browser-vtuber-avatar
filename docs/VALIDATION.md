# 공개 준비 검증 기록

기준일: 2026-10-18. 이 문서는 실제 실행한 검사와 별도 확인이 필요한 항목을 구분합니다.

## 검사 대상

버전 0.2.1의 Windows 데스크톱 앱, 캐릭터팩 입력·에이전트 워크플로우·공개 파일·배포 후보를 대상으로 합니다. 개인용 캐릭터 원본과 프레임은 공개 소스에서 제외합니다.

위 결과는 전문 외부 침투 테스트 인증이 아닙니다. 공격 시나리오는 [위협 모델](THREAT_MODEL.md)에 연결합니다. 모의 서버는 이 테스트가 만든 로컬 서버이며 실제 사용자 계정이나 외부 서비스를 공격하지 않습니다.

검사 명령은 npm test, test:desktop, avatar:check, audit:public, npm audit, package:win, verify:release입니다. 로컬 런타임은 Electron 44.9.0을 사용했습니다. 로컬 소켓 통신을 제한하는 실행 환경에서는 모의 서버 검사가 타임아웃될 수 있으므로 실제 코드 실패와 환경 제한을 구분합니다.

첫 공개 커밋 `83b76aedecdd3a8bc4d224ae399dee68b6f9a096`은 별도의 깨끗한 Linux·Windows 환경에서 [GitHub CI가 성공](https://github.com/cbh456746/browser-vtuber-avatar/actions/runs/39092239319)했습니다. Linux 검사와 Windows 데스크톱·실행파일 검사가 모두 통과했습니다. 후속 변경은 해당 커밋의 Actions 결과를 다시 확인합니다.

## 실제 장치·방송과 구분

2026-10-18에는 추가로 제공된 비공개 일러스트 한 장에서 내장 image_gen 도구로 6개 표정 시트를 실제 생성했습니다. 1254×1254 생성 시트의 불균등한 행 간격은 공통 투명 경계·배율·기준점을 이용해 비공개 사전 처리한 뒤 150개의 512×512 PNG로 분리했습니다. 출력 크기가 원래 그림의 세부 해상도를 증명하지는 않습니다.

150개 모두 고유한 픽셀이며 투명 여백·경계·메타데이터 검사를 통과했습니다. 실제 Electron 설정 창과 방송 창에서 150개 상태를 모두 로드하고, 수동 조작·좌우 반전·초록/자홍 배경을 검사했습니다. 생성 시트·캐릭터팩·미리보기·프롬프트 원문은 비공개로 보관합니다. 방향 각도는 생성 프롬프트의 목표이며 물리적으로 정밀 보정한 추적 각도는 아닙니다.

이 시험에서 빠른 연속 조작의 마지막 입 모양이 누락되는 문제를 발견했습니다. 0.2.1은 20ms 갱신 제한을 유지하면서 마지막 입력을 예약 반영하고, 모드를 전환하면 예약 입력을 취소합니다. 마지막 상태 보존과 모드 전환 회귀 검사를 추가했습니다.

- 이번 자동 시험은 실제 VTube Studio·iPhone 얼굴 추적이 아닌 모의 API를 사용합니다.
- 마이크의 네이티브 동의·권한 정책과 종료 코드는 검토하지만 실제 마이크 신호와 발화는 별도 사용자 시험이 필요합니다.
- OBS에서 실제 장면·녹화·알파·크로마키·오디오가 정상인지 별도 확인해야 합니다.
- 입력 그림마다 생성 품질이 다르므로 새 캐릭터를 만들 때마다 150프레임을 검수합니다. 이번 시험의 성공이 다른 일러스트의 품질이나 자동 제작 성공을 보장하지 않습니다.
- 장시간 부하·모든 디코더 취약점·모든 프롬프트 인젝션·관리자 권한 악성코드를 방어했다고 주장하지 않습니다.

## 배포 상태

소스 공개가 승인된 범위입니다. 실행파일은 로컬 검증용이며 공개 Release에 올리지 않습니다. 코드 서명 인증서가 없어 미서명입니다. 정식 바이너리 배포 전 서명·배포자·무결성·사용자 동작 검증 정책을 확정해야 합니다.

원시 로그·토큰·원본 이미지·개인 캐릭터팩은 이 보고서에 첨부하지 않습니다. 로컬 검증 결과와 SHA-256 정보는 release 폴더에 보관하고 Git에서 제외합니다.
