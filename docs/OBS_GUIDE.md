# OBS 방송 설정 — 주소 입력 없이 창을 선택합니다

## 가장 쉬운 첫 설정

1. Illustration Avatar Studio.exe를 실행하고 캐릭터를 불러옵니다.
2. 앱의 방송 배경을 **초록색**으로 두고 **방송 화면 열기**를 누릅니다.
3. OBS에서 사용할 장면을 선택합니다.
4. 소스의 **+ → 윈도우 캡처**를 누릅니다.
5. 창 목록에서 **Illustration Avatar Studio - 방송 화면**을 선택합니다. 설정 창이 아닌 캐릭터만 보이는 창입니다.
6. 소스를 마우스 오른쪽 버튼으로 눌러 **필터 → 효과 필터 + → 크로마키**를 추가합니다.
7. 키 색상을 초록색으로 선택하고 가장자리를 확인합니다.
8. OBS 미리보기에서 캐릭터 크기·위치를 조절합니다.

URL·로컬 서버 주소를 복사할 필요가 없습니다. 방송 창의 위치는 드래그로 옮길 수 있고 크기도 조절할 수 있습니다. 캡처 중에는 창을 닫거나 최소화하지 않는 편이 안정적입니다.

## 캐릭터에 초록색이 많다면

앱 배경을 자홍색으로 바꾸고 크로마키의 키 색상도 같은 색으로 맞춥니다. 두 방법 모두 캐릭터 일부와 배경 색이 겹치면 영향을 줄 수 있으므로 머리 장식과 옷 가장자리를 확인하세요.

투명 배경 옵션도 있지만, Windows·OBS 버전과 캡처 방식에 따라 알파가 전달되지 않아 검게 보일 수 있습니다. 이 경우 초록 또는 자홍 배경과 크로마키를 사용합니다. 모든 환경에서 투명 캡처가 된다고 보장하지 않습니다.

## 얼굴 추적과 목소리

- VTube Studio가 얼굴을 추적할 때 앱에서 얼굴 추적 모드로 연결합니다.
- 마이크 모드에서는 목소리 크기에 따라 입만 움직입니다. 오디오는 앱이 방송에 전달하지 않습니다.
- 시청자가 목소리를 들으려면 OBS의 **오디오 입력 캡처** 또는 마이크/보조 오디오를 설정합니다.

## 방송 전 1분 녹화

좌우·상하 방향, 눈 감기, 말하기·무음, 연결 중단과 재연결을 확인합니다. 설정 창·작업 표시줄·다른 대화가 캡처되지 않는지도 확인합니다. 이 프로젝트의 자동 테스트는 OBS 장면과 실제 카메라·마이크의 송출 품질을 대신 검증하지 않습니다.
